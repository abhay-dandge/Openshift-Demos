Custom S2I Builder Succeeded!

STATUS: ACTIVE S2I BUILDER: UBI9 PLATFORM: OPENSHIFT

This static website was built and served using a custom Source-to-Image (S2I) builder image based on Red Hat Universal Base Image 9.

S2I Lifecycle Demonstration

  • assemble: Copied application sources from /tmp/src to /opt/app-root/src
  • permissions: Applied group 0 permissions for OpenShift arbitrary UID compatibility
  • run: Spawned HTTP daemon bound to non-privileged port 8080
